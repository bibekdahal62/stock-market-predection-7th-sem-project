# 📈 Stock Market Prediction System

A final-year academic project that predicts stock market trends using Machine Learning techniques. The application analyzes historical stock data to generate predictions and provides users with an intuitive interface for exploring market insights.

## ✨ Features

* Predict stock market trends using machine learning
* Analyze historical stock price data
* Interactive and user-friendly interface
* Data visualization for better insights
* Academic project demonstrating ML and web development concepts

## 🛠️ Tech Stack

* Python
* Django
* Machine Learning (Scikit-learn)
* Pandas & NumPy
* HTML, CSS, JavaScript
* PostgreSQL

## 🚀 Getting Started

```bash
git clone https://github.com/bibekdahal62/stock-market-predection-7th-sem-project.git
cd stock-market-predection-7th-sem-project
pip install -r requirements.txt
python manage.py runserver
```

## 🎓 Academic Project

Developed as a **Final Year (7th Semester) Project** to demonstrate the application of Machine Learning techniques in stock market prediction using historical financial data.
